# HOW TO USE:

The usage should be obvious from the app itself. In *Wordle* you have to guess a random five-letter word by writing other five-letter words to find out which letter is where. But I'm sure you're well aware what *Wordle* is. If not, look [here](https://www.nytimes.com/games/wordle/index.html)

# Features

1. Play a familiar Wordle-like game
2. No daily usage limits
3. blacklist words you do ABSOLUTELY NOT want to play again
4. Track your streak, days on which you played and even your performances in-game in a dedicated Statistics page
5. Play in English, German or French
6. Add time to the mix to make the game more exciting
7. Share your current word with others via a short alphanumeric code for them to try it themself
8. Completely offline with no ads whatsoever
